# 跨境融资契约观察站

海外子公司银团贷款的偿债、担保、资金用途条款分别由法务、财务、业务负责人维护。
本服务把合同条款拆成**可计算约束**（指标方向与阈值、观察周期、报表截止与宽限期、
币种口径版本、责任人与指定复核角色），接收银行报表与人工佐证后逐约束逐期次生成状态，
驱动**通知、提款冻结、指定角色复核**，并以只追加的审计链给出一致解释。

## 核心规则

- **可计算约束**：指标代码/方向/阈值/近阈值带宽，月度或季度观察周期，
  报表截止按合同时区换算绝对时刻（内置时区数据库），宽限期按日历日推算。
- **报表版本链**：同一合同同一期次形成 `ORIGINAL → BACKFILL/REVISION` 链；
  迟到补发、截止前修订、同文件哈希重复上传均保留（重复上传不新增版本、不改关系）。
- **每期状态机**：
  `PENDING → OVERDUE → COMPLIANT / NEAR_THRESHOLD / BREACH_IN_GRACE
   → CONFIRMED_DEFAULT → REVISION_PENDING_REVIEW
   → FALSE_ALARM_WITHDRAWN / CURED / DEFAULT_ACKNOWLEDGED`。
- **通知去重**：去重键 `事件|约束|期次`，近阈值只提醒一次；误报撤回时原通知标记撤回（不删除）。
- **违约处置**：确认违约立即冻结同合同同条款域下所有未发放提款（冻结令互相覆盖，
  一条撤回而另一条仍违约时提款不会被放出），并开启指定角色复核任务；
  复核可撤回误报 / 确认违约 / 认可补救。
- **历史不可变**：状态记录只追加并快照所用条款版本 ID、币种口径与报表版本；
  管理员修订条款必须填写生效时间与影响范围，历史期次不被新口径追溯覆盖。
- **跨重启可追踪**：状态以原子写入的 JSON 文件保存，隔日重启后未决复核、
  冻结令、报表版本链与下一报表截止均可恢复。

## 运行

```bash
go run .                       # 默认 :8080，状态文件 data/observatory.json
PORT=8090 DATA_FILE=/data/loan.json go run .
```

## 主要接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/contracts` | 登记合同 |
| POST | `/api/contracts/{id}/drawdowns` | 登记提款（关联条款域） |
| GET  | `/api/contracts/{id}/upcoming-deadline?from=RFC3339` | 下一报表截止 |
| POST | `/api/covenants` | 三部门负责人登记可计算约束 |
| POST | `/api/covenants/{id}/amendments` | 管理员修订（生效时间+影响范围） |
| GET  | `/api/covenants/{id}/periods/{key}/explain` | 期次状态/版本链/冻结/通知解释 |
| POST | `/api/filings` | 上传银行报表（哈希去重、自动判定补发/修订） |
| POST | `/api/evidence` | 上传人工佐证 |
| POST | `/api/generate` | 生成合同期次下全部约束状态（季度键自动展开月/季期次） |
| GET  | `/api/reviews/pending` | 未决复核清单 |
| POST | `/api/reviews/{id}/decision` | 指定角色复核决定 |
| GET  | `/api/audit` | 只追加审计链 |

请求通过 `X-Actor-Id` / `X-Actor-Role` 头标识操作人；角色决定修订与复核权限。

## 启用前验收场景（已在测试中固化）

1. **跨月指标 + 补发报表**：截止后补发进入近阈值带只提醒一次；二次修订达标后版本链完整、历史只追加。
2. **两条约束同时违约**：同域提款被两张冻结令共同覆盖；一条撤回而另一条确认时提款保持冻结。
3. **撤回误报**：违约后修订达标 → 修订待复核 → 指定角色撤回 → 提款解冻、原违约通知标记撤回。
4. **隔日重启**：文件持久化下未决复核、冻结状态与下一截止时刻均可恢复并继续结案。

另覆盖跨时区截止（上海 17:00 = UTC 09:00）、同一文件重复上传、
条款修订不追溯历史、季度报告月/季期次展开。
